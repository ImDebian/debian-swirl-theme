# debian-swirl-theme
Discord phone Theme inspired of Debian distro — swirl ASCII neon carbon font, with wallpaper.

## Usage

1. Copy the theme link
```
https://raw.githubusercontent.com/ImDebian/debian-swirl-theme/refs/heads/main/Debian-Swirl.json
```
2. Open discord
3. Go to settings
4. Go to themes
5. Click the `+` icon
6. Paste in theme link and install (if you're using enmity you may need to restart, bunny users can skip this)

## Themes+
> [!NOTE]
> Themes+ is required for custom icon colours and overlays and iconpacks
>
> Custom icon colours are applied when themes+ is loaded
1. Copy plugin link
```
https://revenge.nexpid.xyz/themes-plus/
```
2. Go to settings
3. Go to plugins
4. Click the `+` icon
5. Paste plugin link & install
6. Go into themes+ settings and click config
7. Set mode to automatic
